# Ghar Beyond

Static multi-page travel website built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` directly for the basic site. For the cleanest local routing experience, use VS Code Live Server or any static server.

## Deployment
Import this folder into Vercel as a static project. No build command is required.

## Edit business details
Change WhatsApp, phone, email and meeting URL in `js/config.js`.

## Add a destination
Add an object to `js/data/destinations.js`, add its image to `assets/destinations/`, and create a route folder under `destinations/<slug>/` using one of the existing detail page templates.

## Add a package
Add an object to `js/data/packages.js`, add the image to `assets/packages/` or another assets folder, and create a route folder under `packages/<slug>/`.

## Replace placeholders
The gallery/about/CTA images and testimonial text are placeholders. Replace them with approved Ghar Beyond assets and genuine customer reviews before launch.
